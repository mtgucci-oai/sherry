🥂 シェリーってどんなワイン？
What is Sherry?

スペイン南部ヘレス周辺で造られる、辛口から極甘口まである酒精強化ワイン

✨ 4つの特徴

  • ベースはほぼパロミノという個性の少ないブドウ。風味のほとんどは熟成から生まれる
  • 辛口は発酵を最後まで終えてから酒精強化する（ポートは発酵途中）
  • 酵母の膜「フロール」の下で熟成する生物学的熟成と、空気に触れさせる酸化熟成がある
  • ほとんどがノン・ヴィンテージ。ソレラ・システムで古いワインと若いワインを少しずつ混ぜる
補足：マデイラは「加熱＋酸化」、ポートは「抽出＋熟成方法」、シェリーは「フロールの有無＋ソレラ」がスタイルを決める要素です。

📜 歴史：3,000年の歴史と浮き沈み
History
紀元前1000年頃フェニキア人が定住し、ブドウ栽培とワイン造りが始まる（シェリーの最初の記録は紀元前100年）
8〜13世紀イスラム教徒の支配で飲酒は禁止。ただし栽培と醸造は続いた
13世紀〜キリスト教の支配下に。英国・アイルランド・フランドルの商人が輸出し急成長
1500年頃英仏との自由貿易協定。コロンブスの航海後、アメリカ大陸にも大量輸出
1800年代半島戦争、フィロキセラで大打撃。落ち着いた時期には有力なシッパーが誕生
1933年他国の粗悪な「シェリー」に対抗し、スペイン初のワイン統制委員会 Consejo Regulador 設立
1979年出荷量がピーク（150万hL）。その後10年で半減
1970年代後半〜1983年ルマサ（Rumasa）が業界を支配し、安値路線で価格を下げる → 1983年に国有化。多くのボデガが閉鎖・売却・合併
1980年代〜統制委員会が畑・在庫・販売のバランス回復と品質向上を進める
2021年新しい規則：パゴ（畑名）表示、熟成地の拡大、エン・ラマの定義など
💡 ルマサは英国の Harveys の「Bristol Cream」の大口供給元として巨大化した。安いシェリーの大量生産が、その後数十年の業界の重荷となった。

🪨 土壌

⚪ アルバリサAlbariza

石灰・シリカ・粘土ほとんどの畑がこれ
  • 約3,000万年前の水生微生物の殻からできた石灰質。穴が多くスポンジのように雨を蓄え、乾いた生育期に少しずつ放出
  • 乾くと表面に固い膜ができ、蒸発を防ぐ
  • 保水力のおかげで、スペインの他の暑い産地より植栽密度・収量を高くできる（ヘレス 3,500〜4,000本/ha・平均70hL/ha、ラ・マンチャ 1,000〜2,000本/ha）
  • 白い土が日光を反射して成熟を助ける。房は葉で日差しから守る
🟤 バロBarros。粘土が多い土 🟡 アレナArenas。砂質の土（チピオナ周辺など）
💡 シェリーの風味は主に熟成から生まれるため、ブドウに強い凝縮感は不要。だから比較的高い収量でも問題ない。

🍇 3つの主要品種
Grape Varieties

🟢 パロミノPalomino（Palomino Fino / Listán）

🥇 畑の97%辛口・甘味付けタイプの大半
  • 中〜晩熟。乾燥に強く、日差しの強い気候向き。多収
  • ニュートラル（品種の香りが少ない）なのが長所
  • 熟すときに酸が残りやすく、後の熟成で風味が開く

🟢 モスカテルMoscatel（Muscat of Alexandria）

別名 モスカテル・デ・チピオナ
  • 海沿いの町チピオナ周辺の砂質土壌で栽培
  • 晩熟、暑さと乾燥に強い
  • オレンジの花やブドウの香りがするアロマティックな品種

🟢 ペドロ・ヒメネス（PX）Pedro Ximénez

区域内の生産量は1%未満
  • 極甘口の「PX」と、他のシェリーの甘味付けに使う
  • 小粒で皮が薄く、房を天日干しして糖を凝縮しやすい
  • 濃厚なドライフルーツ、糖蜜、プラムの香り

残り3%はモスカテルとPXで半分ずつ。新規則で、フィロキセラ以前に栽培されていた6品種も導入可能に。

🌱 栽培と収穫
Vineyard Management
🚜 機械化剪定・収穫・土壌管理まで機械化に向けて畑を改造中 ✂️ 仕立て伝統は株仕立て・長梢剪定の「ヴァラ・イ・プルガール」。今はコルドン＋短梢が増加（冬の剪定も機械化可）。どちらも大事なのは果実を健康に保つこと 📉 収量上限80hL/ha、実際は60〜70hL/ha 💧 アセルピア収穫後、等高線に沿って溝を掘り、雨水の流出を防いで地中にしみ込ませる（春に戻す）。斜面は10〜15%のゆるやかな丘 🌿 台木333EM、41B、13-5 EVEX。地元開発の13-5 EVEXは石灰に強く（クロロシス防止）乾燥にも強い 🦠 病害虫乾燥しているので病気は少なめ。春の雨後のうどんこ病、害虫のヨーロッパブドウガ（フェロモン・トラップで対策）

🧺 収穫

  • 春霜の心配はない。収穫は8月第1週ごろから内陸の暑い畑で始まり、9月第2週までに海沿いで終わる
  • 秋雨を避けてできるだけ早く。カビは厳禁（特に生物学的熟成用）
  • 目安：潜在アルコール約12%、総酸約5g/L、pH 3.3〜3.5。酸が5g/Lを大きく下回れば補酸
  • 約60%が機械収穫。酸化や微生物を防ぐため夜〜早朝に
  • 天然甘口用のPX・モスカテルはやや遅めに収穫（糖が多いほど乾燥が早い）

🍇 圧搾と発酵
Pressing & Fermentation

🗜️ 圧搾：搾り方でスタイルが変わる

果皮との接触は避ける（フェノール類がフロールの生育を妨げるため）。ブドウは届いたらすぐ圧搾。

果汁特徴主な用途
フリーラン＋プリメラ・イエマ
（最初の軽い搾り）		フェノールが少ない生物学的熟成（フィノ・マンサニーリャ）
セグンダ・イエマ
（強めの圧力）		フェノールが多く、フロールが育ちにくいオロロソ
プレンサ
（最後の搾り）		―新しい樽で発酵させて樽を慣らし、そのワインは蒸留してスピリッツに
  • フリーラン＋1番搾りは全体の60〜75% → オロロソ中心の生産者（例：Fundador）はフリーランをオロロソにも使う
  • 果汁の上限：ブドウ100kgあたり70L

🧪 発酵

  • アルバリサの土ぼこりを除くため、発酵前に清澄（沈殿・遠心分離・浮上法）。補酸もこの時に
  • 畑ごとに分けて発酵し、多くのベースワインを用意
  • 培養酵母で22〜26℃が一般的 → 確実に辛口まで発酵させる（香りは熟成で生まれるので、やや高めの温度でもよい）
  • 多くはステンレス。一部は古樽で発酵してボディを出す
  • 最初の7日で糖の大半が発酵し、残りは数週間かけてゆっくり
  • パロミノはリンゴ酸が特に少ないため、マロラクティック発酵は起きない

🔀 分類と酒精強化
Classification & Fortification
💡 ポイント
フロールは15.5%以下なら育ち、16%を超えると生きられない。だから酒精強化の度数で熟成のルートが決まる。

1️⃣ 第1分類（発酵後）

🌼 生物学的熟成へ

  • 軽く、風味が穏やかなワイン
  • 15〜15.5%に強化（フロールに最適）

🍂 酸化熟成へ

  • ボディがあり、風味が強いワイン
  • 17%に強化（フロールは育たない）→ オロロソのソースとなる
  • 強化には95%のブドウ・スピリッツ（ニュートラルで香りを足さない）
  • 2021年規則：自然に15%に達したベースワインは強化しなくてもよい（EUの承認待ち）
  • 強化後のワインは「ソブレタブラス」と呼ばれ、その年の単一ヴィンテージ。タンクや樽で待機してからソレラへ

2️⃣ 第2分類（数か月後）

🌼 フィノ／マンサニーリャ候補フロールがしっかり張り、フレッシュさを保ったもの。のちにアモンティリャードのソレラへ移ることもある ✂️ パロ・コルタド候補やや繊細さに欠けるもの → 17%に再強化して酸化熟成

🍯 甘口シェリーの造り

天然甘口（PX・モスカテル）

  • 甘味料は加えない
  • ブドウを2〜3週間天日干し → 糖が凝縮し、レーズンのように甘い果汁になる

甘味付け（クリームなど）

  • 辛口に発酵・強化したパロミノを熟成（生物学的・酸化・両方）
  • PXなどで甘味を足す

🏛️ 熟成の場所とボデガ
Where Sherry Matures

📍 熟成できる場所

以前DO Jerez は3つの町（ヘレス、エル・プエルト、サンルーカル＝「Zona de Crianza」）でのみ熟成可 2021年〜生産地域内ならどこでも熟成可 マンサニーリャ必ずサンルーカル・デ・バラメダで熟成 瓶詰めすべてのシェリーは3つの町で瓶詰め・包装

🛢️ 樽：ブッタ（Butt）

  • 主に600Lのアメリカンオーク（1500年代の征服の歴史から。フレンチオークより安い）
  • 新樽の香りは不要なのでとても古い樽を使う
  • 生物学的熟成ではフロールのために約500Lだけ入れる（85〜90%）

🏠 ボデガ（熟成庫）の工夫

  • 厚い壁で温度を一定に
  • 高い天井で暖かい空気を上へ逃がす。樽は3〜4段まで
  • 屋根近くの小さな窓から大西洋の涼しく湿った南西風を入れる。薄いブラインドで日差し・ほこり・虫を防ぐ
  • 土の床に夏は水をまいて温度を下げ、湿度を上げる
それでも夏と冬で条件は変わるため、フロールは一年中同じ厚さを保てないことが多い。

🔁 ソレラ・システム
The Solera System

古いワインに若いワインを少しずつ継ぎ足していく「分別ブレンド」

🧱 しくみ

ソレラ最も古いワインの樽の段 クリアデラ熟成段階ごとの樽のグループ。ソレラの次に古いのが第1クリアデラ、次が第2…
① ソレラから抜くソレラの各樽から一部を抜き、ブレンド・瓶詰めへ
② 第1クリアデラ → ソレラ同じ量を第1クリアデラから抜き、タンクで混ぜてからソレラに補充
③ 第2 → 第1第2クリアデラから抜いて第1クリアデラに補充
④ 繰り返し最も若いクリアデラには、ソブレタブラス（その年の新酒）を補充

📏 ルール

  • 1年に抜けるのはソレラ全体の40%まで → いつも大部分のワインが残る
  • 販売するワインは最低2年熟成

🎛️ 応用

  • クリアデラの数は3〜4段から十数段まで。段数・抜く量と頻度で熟成年数・複雑さ・価格が決まる
  • 途中の段から早めに抜いてもよい：安いフィノは第4・5クリアデラ中心に第1を少し、高級フィノはソレラと第1が多め＋若いワインを少し
  • 別のソレラとブレンドしたり、別のソレラへ移したりもできる（例：フィノのソレラで5年 → アモンティリャードのソレラで8年）
補足：古いワインが若いワインを「教育」し、毎年同じ品質・スタイルを保てるのがソレラの最大の利点です。

🌼 生物学的熟成と 🍂 酸化熟成
Biological & Oxidative Ageing

🌼 フロールが育つ条件

アルコール15.5%以下SO₂を加えない樽は85〜90%・栓はゆるく（酸素が必要）

フロールは4種類の Saccharomyces cerevisiae。ヘレスのブドウの皮やボデガに住んでいて、条件がそろうと自然にワインの表面に膜を張る。

🌼 生物学的熟成🍂 酸化熟成
色酸化から守られ淡いレモン色レモン → 金 → 琥珀 → 褐色
アルコールフロールが消費し下がる水分が先に蒸発し少し上がる（年3〜5%の量が減る）
アセトアルデヒド増える → リンゴ・リンゴの皮・干し草・カモミール、やや苦み少し減る
グリセリンフロールが消費 → 軽いボディ、とても辛口濃縮 → ふくよかで丸いボディ
酢酸減る酢酸・酢酸エチル（揮発酸）が少し増える
その他の香り死んだ酵母の自己分解でナッツ・旨み。青リンゴ・パン・チーズカラメル・ナッツなどの熟成香

🔁 フロールとソレラの関係

  • 若いワインにはフロールの栄養（アルコール・グリセリン・酢酸）が豊富 → 継ぎ足しで栄養を補給し、厚い膜を保つ
  • フィノやマンサニーリャは少量ずつ頻繁に抜く。店頭で新鮮なうちに飲めるように（瓶熟成で良くならず、早く飲むべき）

📦 瓶詰め前の仕上げ

  • 多くは酒石安定化・清澄・ろ過。生物学的熟成のものはフロールを除くためろ過が特に重要
  • 栓はコルク、T字栓、スクリューキャップ

🌼 フィノ／マンサニーリャFino / Manzanilla

🏛️ 統制委員会（Consejo Regulador）

  • 1933年、スペインで最初に登録された統制委員会
  • 畑とボデガの登録、最大収量・ベースワインの最低度数の設定、在庫の回転の監督、年数表示の認証
  • International Sherry Week や専門家向け講座などの販促
  • 1990年代半ば、EU内で「Sherry」の名前を2つのDOだけに限定させた（それまでは白ブドウの酒精強化ワインの総称だった）

📖 シェリー用語集
Glossary

フロールFlor

ワインの表面に膜を張る4種類の酵母。酸化を防ぎ、独特の香りを生む。

生物学的熟成 / 酸化熟成Biological / Oxidative Ageing

フロールの下での熟成／空気に触れさせる熟成。

ソレラ / クリアデラSolera / Criadera

最も古い樽の段／熟成段階ごとの樽のグループ。

ソブレタブラスSobretablas

酒精強化したばかりの、その年の新酒。ソレラに入る前の段階。

ブッタButt

600Lの古いアメリカンオーク樽。

ボデガBodega

シェリーの醸造・熟成庫、また��その会社。

アルバリサAlbariza

石灰・シリカ・粘土の白い土。水を蓄え、乾くと膜を作る。

ポニエンテ / レバンテPoniente / Levante

大西洋からの涼しく湿った西風／北アフリカからの熱く乾いた風。

パゴPago

個性の異なる小さな畑の区画。2021年からラベル表示可。

アセルピアAserpia

収穫後に等高線沿いに溝を掘り、雨水をためる作業。

プリメラ・イエマ / セグンダ・イエマPrimera / Segunda Yema

最初の軽い搾り（フィノ用）／強めの搾り。

アセトアルデヒドAcetaldehyde

フロールが作る成分。リンゴ・干し草・カモミールのような香りをつくる。

エン・ラマEn Rama

清澄や安定化をせず、樽から出したままに近い状態で瓶詰めしたシェリー。

アルマセニスタAlmacenista

熟成・貯蔵だけを行い、シッパーに売る小規模ボデガ。

RCGM

精留濃縮果汁。色や風味を足さずに甘くできる（ペール・クリームに使用）。

Consejo Regulador

シェリーの統制委員会。1933年設立、スペイン初。
